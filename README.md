# 🌳 شجرة عائلة آل ندى | Al-Nada Family Tree Web App

تطبيق ويب تفاعلي حديث وشامل لتوثيق وتصفح شجرة عائلة **آل ندى** الكريمة. يعمل التطبيق بدون أي خوادم معقدة (Serverless / Standalone Single-Page Application)، ومتوافق 100% مع الهواتف الذكية (iOS و Android) وأجهزة الكمبيوتر، مع دعم كامل للغتين العربية والإنجليزية والمظهرين الفاتح والداكن.

> **إعداد وتوثيق: إيهاب ندى**

---

## 📱 التوافق مع الهواتف الذكية (Mobile & Touch Ready)
تم تصميم التطبيق ليعمل بسلاسة فائقة عند فتحه من الهاتف:
- **تحريك وسحب الشجرة باللمس (Touch Panning)**: سحب سلس بالأصبع في جميع الاتجاهات.
- **التكبير والتصغير بإصبعين (Pinch to Zoom)**: تكبير وتصغير الشجرة الهيكلية بسلاسة.
- **أزرار تحكم عائمة مخصصة للموبايل**: أزرار سريعة (`➕`, `➖`, `🎯`, `📂`) أسفل الشاشة للتحكم بيد واحدة.
- **تكيف ذكي مع أبعاد الشاشات الصغيرة**:
  - قوائم وتبويبات قابلة للتمرير الأفقي السلس.
  - إحصائيات مصغرة تتكيف مع عرض شاشات الهواتف.
  - نماذج ونوافذ منبثقة ملائمة لجميع مقاسات الشاشات دون اقتطاع الأزرار.

---

## ✨ المميزات الرئيسية (Key Features)

1. **🌳 الشجرة الهيكلية التفاعلية (Interactive Tree)**:
   - رسم شجري كامل لـ 449 فرداً موزعين على 10 أجيال و 7 فروع رئيسية.
   - خطوط ربط هندسية دقيقة ومتناسقة في اللغتين العربية (RTL) والإنجليزية (LTR).
   - إمكانية طي وبسط الأفرع، والتكبير والتصغير، والتحريك الحر.
   - تمييز الأجداد وأرقام الأجيال وعدد الأبناء في كل بطاقة.

2. **🗂️ مستكشف الفروع (Branches Explorer)**:
   - بطاقات مخصصة لكل فرع من فروع العائلة السبعة (فرع محمود، فرع سالم، فرع أحمد، فرع محمد، فرع عبد الله، فرع خليل، فرع إبراهيم).
   - استعراض هرمي داخلي لكل فرع وإحصاء عدد أفراده.

3. **📋 دليل الأسماء والبحث الفوري (Directory & Instant Search)**:
   - بحث فوري وسريع بالاسم، الجيل، أو الملاحظات، مع إبراز الفرد في الشجرة مباشرة.
   - فلاتر مخصصة حسب الفرع ورقم الجيل.

4. **📊 إحصائيات ورؤى العائلة (Statistics & Insights)**:
   - قائمة الأسماء الأكثر تكراراً في العائلة مع أشرطة بيانية تفاعلية.
   - التوزيع العددي للأجيال ونسب الفروع.
   - توثيق القيود والملاحظات التاريخية وسنوات الوفيات الموثقة بالرسمة الأصلية.

5. **👥 نظام إدارة المستخدمين والصلاحيات (Users & Roles Management)**:
   - **🛡️ المشرف العام (Super Admin)**: صلاحيات كاملة لإدارة الشجرة والمستخدمين وكلمات المرور (`ehab`).
   - **✍️ محرر معتمد (Branch Editor)**: صلاحية إضافة وتعديل الأفراد مع إمكانية **حصر صلاحيته بفرع محدد** (مثل فرع سالم أو فرع محمود) لضمان دقة النسب.
   - **🔍 مدقق أنساب (Auditor)**: صلاحية مراجعة وتوثيق الملاحظات.
   - **👁️ زائر عادي**: تصفح، بحث، قراءة، وطباعة فقط.

6. **📜 سجل توثيق التعديلات (Audit Trail & Activity Log)**:
   - تسجيل تلقائي لكل عملية إضافة أو تعديل أو حذف بالاسم الصريح للمحرر والوقت الدقيق لضمان الحفاظ على صحة الشجرة ومسؤولية التعديل.

7. **🖨️ تصدير الشجرة كملف PDF / طباعة ورقية**:
   - زر مخصص لطباعة الشجرة بنمط عريض (Landscape) وجودة عالية، أو حفظها مباشرة بصيغة PDF.

8. **💾 استيراد وتصدير النسخ الاحتياطية (JSON Backup)**:
   - إمكانية حفظ نسخة احتياطية من بيانات الشجرة أو استيرادها بضغطة زر.
   - تصدير واستيراد قائمة المحررين والصلاحيات.

## 🚀 تشغيل ونشر المشروع على GitHub Pages (Live Website)

لجعل الشجرة متاحة عبر الإنترنت لجميع أفراد العائلة برابط مباشر يمكن فتحه من أي هاتف أو كمبيوتر:

### 1. رفع المشروع إلى GitHub:
افتح موجه الأوامر (Terminal / PowerShell) في مجلد المشروع ونفّذ:
```bash
# تهيئة المستودع
git init

# إضافة جميع الملفات
git add .

# حفظ التعديلات
git commit -m "Initial release: Al-Nada Family Tree Web Application"

# تعيين الفرع الرئيسي
git branch -M main

# ربط المستودع بحسابك على GitHub (استبدل username و repo-name ببياناتك)
git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git

# رفع الملفات
git push -u origin main
```

### 2. تفعيل GitHub Pages (خلال دقيقة واحدة):
1. اذهب إلى صفحة المستودع على **GitHub**.
2. اضغط على **Settings** ⚙️ ثم اختر **Pages** من القائمة الجانبية.
3. تحت خيار **Branch**، اختر `main` واجعل المجلد `/ (root)` ثم اضغط **Save**.
4. سيعطيك GitHub رابطاً مباشراً لموقعك:
   `https://<YOUR_USERNAME>.github.io/<REPO_NAME>/`
5. يمكنك الآن إرسال هذا الرابط إلى جميع أفراد العائلة ليفتحوه على هواتفهم مباشرة!
